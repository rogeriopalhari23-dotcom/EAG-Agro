## Problemas encontrados (para decidir antes de mesclar)

1. **Backend dividido entre as branches.** O redesign depende de acréscimos que só existem em `redesign-ui` (coordenadas
   dos compradores no resultado do Radar, filtros de Empresas, tipo de contato no resumo da empresa, rota
   do mapa); a produção tem o que só existe em `v2-revisao-2` (classificação de notificações, remoção de supressão,
   migração 0031). Com o backend publicado, o mapa do Radar aparece **sem compradores** ("4 desta página sem posição") e
   os filtros de Empresas são **ignorados** sem aviso (captura `radar-resultado` da prévia 8792). Antes de publicar é
   preciso juntar as duas branches; a junção foi recusada nesta sessão e fica para a sua autorização.
2. Na prévia 8791 (backend da branch), a tela Supressão mostra o formulário de remoção, mas a rota não existe nesse
   backend — usar a 8792 para essa tela até a junção.
3. Nas capturas de página inteira o menu lateral para no fim da primeira tela; no navegador ele fica fixo (efeito só da
   captura).
4. Publicar o redesign exige: junção das branches, `npm run check`, testes de interface (smoke, teclado, mapa), sua
   conferência visual e, para o mapa, nada além do que já está no R2 (CSP: só `blob:` em `img-src`).
